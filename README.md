# 🛗 Elevator Simulator

A simple elevator simulator built with **HTML, CSS, and JavaScript**.

Users can select a floor by clicking the floor buttons, and the elevator moves to the selected floor with a simple animation.

## 📌 Project Overview

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and CSS animations.

The elevator starts on the **1st floor**. When a user selects another floor, JavaScript calculates the elevator's position and moves it to the selected floor.

## Ideas

🏢 Floors: 1, 2, 3, 4, 5
🔘 User clicks a floor button
🛗 Elevator moves to that floor
📺 Display shows the current floor
⬆️⬇️ Elevator moves visually

## ✨ Features

- 🛗 Elevator movement animation
- 🔢 Floor selection buttons
- 📺 Current floor display
- 📢 Elevator status message
- ⬆️ Move to higher floors
- ⬇️ Move to lower floors
- 🚫 Prevent movement when already on the selected floor
